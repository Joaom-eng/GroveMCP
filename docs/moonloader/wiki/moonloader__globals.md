# Глобальные переменные и константы | Modding Wiki

Fonte: https://wiki.blast.hk/moonloader/globals

Глобальные переменные и константы, которые добавляет MoonLoader. Они доступны с самого начального этапа загрузки скрипта.

Тип |  Название |  Описание |

Ped |  [PLAYER_PED](https://wiki.blast.hk/moonloader/lua/PLAYER_PED) |  Хэндл персонажа игрока. Применим во многих функциях, принимающих значение типа `Char` в качестве параметра. |

Player |  [PLAYER_HANDLE](https://wiki.blast.hk/moonloader/lua/PLAYER_HANDLE) |  Идентификатор активного игрока. Применим во многих функциях, принимающих значение типа `Player` в качестве параметра. |

Ped |  playerPed |  Псевдоним переменной `PLAYER_PED`. С версии .022 считается устаревшим. |

Player |  playerHandle |  Псевдоним переменной `PLAYER_HANDLE`. С версии .022 считается устаревшим. |

null |  [null](https://wiki.blast.hk/moonloader/lua/null) |  Специальная константа, использующаяся при сериализации и десериализации JSON. |
