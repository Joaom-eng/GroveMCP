# script_version | Modding Wiki

Fonte: https://wiki.blast.hk/moonloader/lua/script_version

```lua
script_version(string version)
```

## Описание

Задаёт текстовую версию скрипта.

## Аргументы

`string version` версия

## Пример использования

```lua
script_version("0.2.3-beta")

function main()
  -- ...
end
```
