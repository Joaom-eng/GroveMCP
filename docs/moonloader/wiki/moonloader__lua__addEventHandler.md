# addEventHandler | Modding Wiki

Fonte: https://wiki.blast.hk/moonloader/lua/addEventHandler

```lua
addEventHandler(string eventName, function callback)
```

## Описание

Добавляет обработчик [события](https://wiki.blast.hk/moonloader/events) по названию.

## Аргументы

`string eventName` название события
 `function callback` функция-обработчик
