# Событие onSystemMessage | Modding Wiki

Fonte: https://wiki.blast.hk/moonloader/lua/onSystemMessage

```lua
onSystemMessage(string msg, int type, LuaScript s)
```

## Описание

Вызывается когда MoonLoader добавляет новое сообщение в лог.

## Входящие значения

`string msg` текст сообщения
 `int type` тип сообщения
 `LuaScript s` скрипт, с которым связано сообщение
