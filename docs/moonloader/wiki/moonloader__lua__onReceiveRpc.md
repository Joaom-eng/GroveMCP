# Событие onReceiveRpc | Modding Wiki

Fonte: https://wiki.blast.hk/moonloader/lua/onReceiveRpc

Только SA:MP. Требует наличие плагина [SAMPFUNCS](https://wiki.blast.hk/sampfuncs).

```lua
bool process=true, int id, Bitstream bitStream = onReceiveRpc(int id, Bitstream bitStream)
```

## Описание

Выполняется перед обработкой входящего RakNet-RPC. Данные в виде битстрима и ид пакета передаются параметрами при вызове.
 Событие имеет все те же возвращаемые параметры, что и входящие, они предназначены для подмены значений.
 Самый первый параметр `bool process` отвечает за продолжение обработки пакета стандартным обработчиком (true - будет обработан, false - проигнорирован).
 Любые из всех параметров могут быть опущены, если в них нет нужды.

Совет: если не требуется подменять входящие значения и отменять обработку RPC, то не возвращайте никакие значения, включая параметр `process` - это увеличит производительность.

## Входящие значения

`int id` идентификатор RPC
 `Bitstream bitStream` данные

## Возвращаемые значения

`bool process` передать на обработку
 `int id` идентификатор RPC
 `Bitstream bitStream` данные
