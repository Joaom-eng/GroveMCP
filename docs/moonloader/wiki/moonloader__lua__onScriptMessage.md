# Событие onScriptMessage | Modding Wiki

Fonte: https://wiki.blast.hk/moonloader/lua/onScriptMessage

```lua
onScriptMessage(string msg, LuaScript s)
```

## Описание

Вызывается когда любой скрипт добавляет сообщение в лог.

## Входящие значения

`string msg` текст сообщения
 `LuaScript s` скрипт добавивший сообщение
